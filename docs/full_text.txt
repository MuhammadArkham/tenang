Row Level Security (RLS)
Wajib diaktifkan â€” user hanya bisa akses data miliknya sendiri.
ALTER TABLE users ENABLE ROW LEVEL SECURITY;
ALTER TABLE mood_entries ENABLE ROW LEVEL SECURITY;
ALTER TABLE journal_entries ENABLE ROW LEVEL SECURITY;
ALTER TABLE habit_logs ENABLE ROW LEVEL SECURITY;
 
-- User hanya bisa akses data sendiri
CREATE POLICY "mood_own" ON mood_entries
  FOR ALL USING (auth.uid()::text = user_id::text);
 
-- Resources: semua bisa baca, tidak ada yang bisa edit via client
CREATE POLICY "resources_read" ON resources
  FOR SELECT USING (is_active = TRUE);
Useful Queries
Weekly mood aggregation
SELECT
  DATE(created_at AT TIME ZONE 'Asia/Jakarta') AS day,
  ROUND(AVG(mood_score)::numeric, 2) AS avg_mood,
  COUNT(*) AS entry_count
FROM mood_entries
WHERE user_id = $1
  AND created_at >= NOW() - INTERVAL '7 days'
GROUP BY day ORDER BY day ASC;
Korelasi screen time vs mood
SELECT
  DATE(h.created_at AT TIME ZONE 'Asia/Jakarta') AS day,
  h.screen_time_hours,
  m.mood_score
FROM habit_logs h
LEFT JOIN mood_entries m
  ON DATE(h.created_at AT TIME ZONE 'Asia/Jakarta')
   = DATE(m.created_at AT TIME ZONE 'Asia/Jakarta')
  AND h.user_id = m.user_id
WHERE h.user_id = $1
  AND h.created_at >= NOW() - INTERVAL '14 days'
ORDER BY day ASC;

Architecture Decision Records
Kenapa setiap teknologi dipilih â€” bahan jawab pertanyaan judge lomba

Dokumen ini mencatat keputusan arsitektur beserta alasannya. Berguna saat presentasi lomba, code review, atau onboarding.

Tradeoff
ADR-001
React + Vite
Ekosistem terbesar, Vite jauh lebih cepat dari CRA, familiar
Vue 3 lebih ringan tapi ekosistem lebih kecil; Next.js overkill untuk MVP
ADR-002
FastAPI
Auto-generate Swagger, Pydantic validation, async native untuk Gemini
Express.js lebih familiar tapi Python lebih natural untuk AI/ML work
ADR-003
Supabase
Free tier cukup untuk MVP, Auth + RLS built-in, PostgreSQL relasional
Free tier auto-pause 1 minggu â€” butuh cron job ping sebagai workaround
ADR-004
Gemini 2.5 Flash
Free tier 15 RPM/1500 req/hari, sangat baik untuk Bahasa Indonesia
Rate limit jadi bottleneck jika user tiba-tiba banyak â€” perlu queue
ADR-005
Vercel
CDN global, auto-deploy dari GitHub, preview deployment per PR
Cloudflare Pages lebih cepat di Asia tapi Vercel lebih dioptimalkan untuk React
ADR-006
Render
Support Python native, deploy dari GitHub, free tanpa credit card
Cold start 30-60 detik â€” mitigasi: loading state "Memuat server..." di FE
ADR-007
TanStack Query
Caching otomatis, loading/error state built-in, invalidation mudah
SWR lebih ringan tapi fitur lebih terbatas; Redux Toolkit Query overkill
ADR-008
Zustand
Minimal boilerplate, tidak butuh Provider wrapper, bundle < 1KB
Redux lebih structured tapi terlalu heavy; Context API rawan re-render
ADR-009
Zero-cost infra
Developer tidak punya kartu kredit â€” semua pakai free tier
Cold start, auto-pause DB, rate limit â€” diterima sebagai tradeoff MVP
